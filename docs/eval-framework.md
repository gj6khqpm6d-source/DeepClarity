# Agent 评估框架(五层模型)

> 工业界标准分层:任务完成 → 输出质量 → 效率成本 → 鲁棒性 → 安全对齐。
> 每层独立评估,不混在一张表里。

---

## 第 1 层:任务完成度

> "给定任务,agent 完成了没有?"

| 项 | 状态 | 说明 |
|---|---|---|
| 端到端报告生成率 | ✅ 100% | 多次回归测试(Tavily/DDG)均成功出报告 |
| 图终止保证 | ✅ | 3 轮硬上限 + 60s 超时降级,循环必然终止 |
| 固定任务集回归 | ❌ 未做 | 需 5-20 个固定查询+完成定义定义,样本不够暂未建 |
| 边界测试 | ⚠️ 部分 | 空输入/超长输入未测;多语言已覆盖(中英文) |

**结论**:任务完成率高且有终止保证;缺固定回归集(需 token 预算)。

## 第 4 层:鲁棒性(最强项)

> "正常好用,异常情况下呢?"

| 项 | 状态 | 对应修复 |
|---|---|---|
| 澄清死循环防护 | ✅ | 修复 #1:3 轮硬上限 + 代码决策 |
| 无记忆防护 | ✅ | 修复 #2:checkpointer 持久化 |
| 搜索限流容错 | ✅ | 修复 #3:分层重试 + 单查询级容错 |
| UI 静默防护 | ✅ | 修复 #4:追问/推进标记区分 |
| LLM 调用挂起防护 | ✅ | 修复 #5:60s 超时降级 |
| 并发突发防护 | ✅ | 修复 #6:Semaphore 限流 |
| 向量记忆降级 | ✅ | embedding 挂了→静默 no-op |
| 故障注入测试 | ✅ | HangingModel 假模型 2s 超时测试通过 |

**结论**:鲁棒性是最强层,6 个修复覆盖超时/限流/死循环/静默失败,全部有定向测试验证。

---

## 第 5 层:安全与对齐

> "好用且可靠,但安全吗?"

| 项 | 状态 | 说明 |
|---|---|---|
| Prompt injection | ❌ 未做 | 研究 agent 读不可信网页,最大风险;网页可藏指令操控 agent |
| 幻觉/groundedness | ⚠️ 基建有 | evaluators.py 有 groundedness 维度;缺实测数据 |
| 有害内容 | ❌ 未做 | — |
| 数据泄露 | ❌ 未做 | 系统提示、API key 可能通过网页内容泄露 |
| 向量记忆来源溯源 | ✅ | recall 工具返回 source URL,可追溯 |

**结论**:未做系统性安全测试;prompt injection 是最大未覆盖风险(研究 agent 读不可信网页)。
